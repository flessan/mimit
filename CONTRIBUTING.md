# Contributing to mim-it

Thank you for helping make mim-it a better community project.

mim-it is an independent, community-led continuation of [georapbox/meme-generator](https://github.com/georapbox/meme-generator). We build on the upstream project's work and preserve its original attribution and license. Contributions to this repository help shape the future of this fork.

## Ways to contribute

- Report reproducible bugs and browser-specific issues.
- Suggest features and discuss possible approaches.
- Improve the editor, accessibility, responsive behavior and performance.
- Update documentation, translations and examples.
- Test changes on desktop and mobile browsers.

## Before opening a pull request

1. Search existing issues and pull requests to avoid duplicating work.
2. For large changes, open an issue or discussion first so the community can agree on the direction.
3. Keep each pull request focused and explain its user-facing impact.
4. Preserve upstream notices and third-party licenses when modifying or adding assets.
5. Do not include private user images, credentials, API tokens or other secrets in commits.

## Local checks

Use Node.js 24 and npm 11.17 or newer.

```sh
npm ci
npm run lint
npm run build
```

Describe the checks you ran in your pull request. If a check cannot be run, mention that clearly.

## Project stewardship

The project aims to remain open, collaborative and community-led. Discussions about features, priorities and project direction should happen in public issue or pull request threads wherever practical.

Participation does not guarantee that a proposal will be accepted. Maintainers may ask for revisions, tests or a narrower scope to keep the project reliable and maintainable.

Please be respectful, assume good intent and focus criticism on the work rather than the person.
